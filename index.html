팁

숙소

10/26 처음부터 다시 골랐어요. 기준은 ① 하카타역에서 유모차로 5분 안 ② 아기 침대 ③ 냉장고·전자레인지 ④ 짐 배송 제휴예요.

1순위 · 미야코 호텔 하카타 (都ホテル 博多)

  • 하카타역 직결, 지쿠시 출구 쪽 확인
  • 전 객실 30㎡ 이상이라 아기 침대를 넣어도 여유 있어요 부분 확인
  • 아기 침대 무료(수량 한정, 미리 신청), 아기 욕조, 기저귀 휴지통, 3층 수유실 확인
  • 호텔 레스토랑에서 가져간 이유식 데우기, 분유용 뜨거운 물 제공. 객실에 냉장고, 가습 공기청정기 확인
  • 체크아웃이 12시라 일요일이 여유로워요. 체크인 전후 짐 보관 무료, 호텔로 택배 미리 보내기 가능 확인
  • 카고패스: 공항 → 호텔만 돼요. 호텔 → 공항은 안 돼요 확인
  • 아쉬운 점: 객실 전자레인지는 자료가 없어요 미확인 하카타 한큐는 역 반대편(하카타 출구) 쪽이라 역 안을 가로질러야 해요.

방에서 이유식을 직접 데우려면 · 아미스타 호텔 후쿠오카

  • 하카타 출구에서 걸어서 약 6분 부분 확인 자료에 따라 8분이라는 곳도 있어요.
  • 전 객실 IH 주방, 전자레인지, 냉장고. 객실 31㎡부터 확인
  • 아기 침대: 공식 사이트는 있다고 하고, 예약 사이트 한 곳은 없다고 해요. 예약 전에 전화로 확인하세요 부분 확인
  • 카고패스: 공항 → 호텔, 호텔 → 공항 둘 다 돼요 확인

그 밖의 후보

  • 오리엔탈 호텔 후쿠오카 하카타 스테이션: 지쿠시 출구에서 걸어서 1분, 지하로 연결. 아기 침대 무료(일부 객실 불가). 체크아웃 11시. 냉장고·전자레인지·객실 크기는 자료가 없어요 부분 확인
  • 리치먼드 호텔 하카타에키마에: 걸어서 약 4분. 8층에 공용 전자레인지. 카고패스 양방향 가능. 대신 방이 작아요(트윈 약 26㎡) 부분 확인
  • 제외: JR큐슈 호텔 블라섬 하카타 중앙은 아기 침대를 추가할 수 없다는 예약 사이트 정보가 있어서 뺐어요.

사가와 당일 배송 제휴 여부는 호텔별로 확인하지 못했어요 미확인 아기 침대는 수량이 적으니 예약하자마자 신청하세요.

아기와 이동
  • 가벼운 접이식 유모차를 추천해요.
  • 택시는 카시트가 없는 경우가 많아서 가까운 거리 위주로 타세요.
  • 공항↔하카타역, 하카타역↔텐진은 지하철 공항선 한 줄로 이어져요.
짐 · 짐 드는 사람이 아빠 혼자일 때

역할 나누기

  • 엄마는 아기띠로 아기를 안고, 유모차는 비워서 짐 카트로 써요. 쇼핑백은 유모차 손잡이와 아래 바구니에 실어요.
  • 아빠는 기저귀 가방 백팩 1개와 캐리어만 맡아요. 손 하나는 비워 두세요.

가져갈 짐 줄이기

  • 기저귀, 물티슈, 이유식은 1~2일치만 가져가고, 나머지는 토요일 아카짱혼포나 약국에서 사요.
  • 여행 중에 쓸 소모품은 면세로 사지 마세요. 일본에서 일부라도 쓰면 출국 때 세금을 다시 걷어요 확인
  • 캐리어 안에 접는 보조 가방을 넣어 가면 돌아올 때 쇼핑한 물건을 담을 수 있어요.

짐 배송 서비스

  • 도착일, 공항 → 호텔: 사가와 큐빈 국제선 터미널 1층. 1개 1,500엔(60~160cm), 16시까지 접수, 18시 이후 도착. 시내 제휴 호텔만 돼요 확인 금요일 17:30 복귀라 시간이 맞아요.
  • 공항 → 호텔 (다른 업체): 카고패스. 1개 550엔부터(크기별), 시내 약 200개 호텔. 14시까지 맡기면 18시 이후 수령이라는 안내가 있어요 부분 확인
  • 귀국일, 하카타역 → 공항: 카고패스 하카타역(Crosta 하카타) 카운터에서 1개 1,500엔 확인 맡기는 마감 시간과 공항 수령 위치는 공식 사이트에서 확인하세요 미확인
  • 호텔 → 공항 배송까지 쓰려면 아미스타나 리치먼드처럼 카고패스 양방향 호텔을 고르세요. 미야코 호텔이면 일요일엔 택시가 답이에요.

일요일 공항 가는 길

  • 쇼핑으로 짐이 늘었으면 지하철 대신 호텔 앞에서 택시를 타는 게 편해요. 거리가 짧아서 카시트 걱정이 적어요. 소요 시간은 미확인
  • 유모차는 항공사 카운터에 맡기지 말고 탑승구까지 가져가서 맡길 수 있는지 항공사에 확인하세요.
식사
  • 쇼핑하는 건물 안에서 해결하면 이동이 줄어요(금 한큐, 토 라라포트).
  • 테이블석과 유아 의자가 있는 곳을 고르세요.
  • 짠 국물 음식은 아기에게 부담이라 이유식은 따로 챙기세요.
