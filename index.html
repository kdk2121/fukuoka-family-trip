팁

숙소

조건: 방에서 취사 가능 + 하카타역 도보권 + 아기 침대 + 짐 배송 제휴. 하카타역 5분 안에는 세 조건을 다 갖춘 곳이 없어서 6분까지 넓혔어요.

1순위 · 아미스타 호텔 후쿠오카 (AMISTAD HOTEL FUKUOKA)

  • 하카타역 하카타 출구에서 걸어서 약 6분 확인 한큐가 같은 하카타 출구 쪽이에요.
  • 전 객실 IH 주방, 전자레인지, 냉장고, 조리 도구. 이유식을 방에서 만들 수 있어요 확인
  • 추천 객실: 그랜드 트윈(31㎡). 세탁기와 욕실 건조가 있어서 아기 옷을 빨아 말릴 수 있어요. 슈피리어 트윈은 같은 크기지만 세탁기가 없어요 확인
  • 침대가 140cm 롱 더블 2개라 아기와 같이 자기에도 넉넉해요.
  • 아기 침대: 공식 가족 안내에는 있다고 나오지만 예약 사이트 한 곳은 없다고 해요. 예약 전에 전화로 확인하세요 부분 확인
  • 카고패스: 공항 → 호텔, 호텔 → 공항 둘 다 돼요 확인
  • 체크인 15:00, 체크아웃 11:00 확인
  • 식기, 냄비가 객실 목록에 따로 적혀 있지 않아요. 아기 식기는 챙겨 가세요 미확인

2순위 · 도큐 스테이 하카타

  • 지쿠시 출구에서 걸어서 약 8분 부분 확인
  • 전 객실 세탁건조기와 전자레인지. 미니 주방은 레지덴셜 더블·트윈 객실만 있어요 부분 확인
  • 카고패스: 공항 → 호텔만 돼요. 아기 침대는 자료가 없어요 미확인

취사를 포기하면

  • 미야코 호텔 하카타: 하카타역 직결, 30㎡ 이상, 아기 침대 무료, 레스토랑에서 이유식 데우기·분유 물. 체크아웃 12시. 방에 전자레인지는 자료가 없어요 확인

아기 침대는 어느 호텔이든 수량이 적으니 예약하자마자 신청하세요.

아기와 이동
  • 가벼운 접이식 유모차를 추천해요.
  • 택시는 카시트가 없는 경우가 많아서 가까운 거리 위주로 타세요.
  • 국제선 터미널은 지하철과 바로 이어지지 않아요. 짐이 많으면 국제선 ↔ 숙소는 택시나 직행 버스가 편해요.
  • 하카타역 ↔ 텐진은 지하철 공항선 한 줄로 이어져요.
짐 · 짐 드는 사람이 아빠 혼자일 때

역할 나누기

  • 엄마는 아기띠로 아기를 안고, 유모차는 비워서 짐 카트로 써요. 쇼핑백은 유모차 손잡이와 아래 바구니에 실어요.
  • 아빠는 기저귀 가방 백팩 1개와 캐리어만 맡아요. 손 하나는 비워 두세요.

가져갈 짐 줄이기

  • 기저귀, 물티슈, 이유식은 1~2일치만 가져가고, 나머지는 토요일 아카짱혼포나 약국에서 사요.
  • 여행 중에 쓸 소모품은 면세로 사지 마세요. 일본에서 일부라도 쓰면 출국 때 세금을 다시 걷어요 확인
  • 캐리어 안에 접는 보조 가방을 넣어 가면 돌아올 때 쇼핑한 물건을 담을 수 있어요.

짐 배송 서비스

  • 도착일, 공항 → 호텔: 사가와 큐빈 국제선 터미널 1층. 1개 1,500엔(60~160cm), 16시까지 접수, 18시 이후 도착. 시내 제휴 호텔만 돼요 확인 금요일 17:30 복귀라 시간이 맞아요.
  • 공항 → 호텔 (다른 업체): 카고패스. 1개 550엔부터(크기별), 시내 약 200개 호텔. 14시까지 맡기면 18시 이후 수령이라는 안내가 있어요 부분 확인
  • 귀국일, 하카타역 → 공항: 카고패스 하카타역(Crosta 하카타) 카운터에서 1개 1,500엔 확인 맡기는 마감 시간과 공항 수령 위치는 공식 사이트에서 확인하세요 미확인
  • 아미스타 호텔은 카고패스로 호텔 → 공항도 보낼 수 있어요. 일요일 아침 프런트에 캐리어를 맡기고 몸만 나가면 돼요. 맡기는 마감 시간은 호텔에 확인하세요 미확인

일요일 공항 가는 길

  • 쇼핑으로 짐이 늘었으면 지하철 대신 호텔 앞에서 택시를 타는 게 편해요. 거리가 짧아서 카시트 걱정이 적어요. 소요 시간은 미확인
  • 유모차는 항공사 카운터에 맡기지 말고 탑승구까지 가져가서 맡길 수 있는지 항공사에 확인하세요.
식사
  • 쇼핑하는 건물 안에서 해결하면 이동이 줄어요(금 한큐, 토 라라포트).
  • 테이블석과 유아 의자가 있는 곳을 고르세요.
  • 짠 국물 음식은 아기에게 부담이라 이유식은 따로 챙기세요.
